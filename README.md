# Reto F1025 - Landing Page (Impulse-X)

Este paquete contiene la página web lista para ser publicada en **GitHub Pages**.

## Contenido del ZIP:
- `index.html`: Estructura y diseño principal de la landing page.
- `README.md`: Instrucciones de uso.

## Pasos para publicar en GitHub Pages:

1. **Agrega tu archivo de logo:**
   - Toma el archivo de tu logo (`Impulse-X_logo_horizontal_fondo_oscuro.png`) y colócalo en esta misma carpeta al lado de `index.html`.

2. **Sube los archivos a GitHub:**
   - Crea un nuevo repositorio en GitHub (ej. `reto-f1025`).
   - Sube tanto `index.html` como `Impulse-X_logo_horizontal_fondo_oscuro.png` directamente a la rama principal (`main`).

3. **Activa GitHub Pages:**
   - En tu repositorio de GitHub, ve a **Settings** > **Pages**.
   - En **Build and deployment** > **Branch**, selecciona `main` (o `master`) y carpeta `/ (root)`.
   - Haz clic en **Save**. En un par de minutos tu página estará activa en internet.
